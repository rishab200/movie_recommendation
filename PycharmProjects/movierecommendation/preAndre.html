The Tradeoff — when each matters
High Recall Priority

Cancer Detection

Never miss a real cancer case, even if it means some false alarms. Missing a true positive (FN) is catastrophic. False alarms can be investigated further.

High Precision Priority

Spam Filter

Better to let some spam through than to block an important email. A false positive (FP) costs more than a false negative here.

Balance Both

Search Engine

Results should be relevant (precision) but also complete (recall). Use the F1 score when neither metric can dominate.

High Recall Priority

Fraud Detection

Catch as much fraud as possible. A missed fraud case costs more than reviewing a false alarm. Recall takes priority here.
